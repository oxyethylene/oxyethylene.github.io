# Installing on Windows with CUDA support

First, at PyTorch [Start Locally](https://pytorch.org/get-started/locally/), select `Stable` -> `Windows` -> `Pip` -> `Python` -> `CUDA 13.0`,
then you can get a command like `pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cu130`.
